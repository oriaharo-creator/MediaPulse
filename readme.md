MediaPulse is a .Ipa file app made for iphones. The app uses a youtube converter to be able to download videos from anywhere as long as you have wifi. It's perfect for flights and situations when you don't have internet. It has a built in search for songs and videos that you want to find then download.

 INSTRUCTIONS

 Find releases then download the latest .ipa and then use a sideload tool like sidestore, altstore, or even Ksign and Esign.
